## 문제 1 (쉬움) 섭씨 → 화씨

`F = C × 9 / 5 + 32`. 결과는 float로 반환합니다.

| 입력 | 출력 |
| --- | --- |
| `0` | `32.0` |
| `100` | `212.0` |
| `-40` | `-40.0` |

## 문제 2 (쉬움) 인사말 만들기

| 입력 | 출력 |
| --- | --- |
| `"민수", 25` | `"안녕하세요, 민수님! 내년에는 26살이 되시네요."` |
| `"Alice", 0` | `"안녕하세요, Alice님! 내년에는 1살이 되시네요."` |

공백·문장부호까지 정확히 같아야 테스트가 통과합니다.

## 문제 3 (보통) 학습 소요 시간 표시

모델 학습 로그에 "총 3725초 걸림"보다 "1시간 2분 5초"가 읽기 쉽죠.

| 입력 | 출력 |
| --- | --- |
| `3725` | `"1시간 2분 5초"` |
| `59` | `"0시간 0분 59초"` |
| `90061` | `"25시간 1분 1초"` (일 단위로 넘기지 않음) |

## 문제 4 (보통) 미니배치 개수

딥러닝은 데이터를 한꺼번에가 아니라 **배치** 단위로 나눠 학습합니다. 남는 샘플도 배치 하나로 칩니다.
**if 없이** 산술 연산만으로 풀어 보세요. 반환값은 `int`여야 합니다.

| 입력 | 출력 |
| --- | --- |
| `1000, 32` | `32` |
| `64, 32` | `2` |
| `5, 10` | `1` |

## 문제 5 (도전) 데이터로더 요약

| 입력 | 출력 |
| --- | --- |
| `1000, 32` | `"샘플 1000개 / 배치 크기 32 → 배치 32개, 마지막 배치 8개"` |
| `64, 32` | `"샘플 64개 / 배치 크기 32 → 배치 2개, 마지막 배치 32개"` |

나누어떨어질 때 마지막 배치 크기는 `0`이 아니라 `batch_size`입니다. 역시 **if 없이** 풀어 보세요.
