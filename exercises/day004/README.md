## 문제 4 (보통) 로그 한 줄에서 숫자 더하기

| 입력 | 계산 | 출력 |

## 문제 5 (도전) 경사하강법은 몇 번 만에 수렴할까?

가장 단순한 모델: 파라미터 `w` 하나, 손실 함수 `loss = (w - 3) ** 2` (정답은 w = 3).
경사하강법은 매 step마다 다음처럼 `w`를 고칩니다.

```
grad = 2 * (w - 3)     # 손실의 기울기
w = w - lr * grad      # 기울기 반대 방향으로 lr 만큼 이동
```

**업데이트를 몇 번 해야 처음으로 `loss < tol`이 되는지** 반환하세요.

1. 업데이트하기 **전에** 이미 `loss < tol`이면 `0`
2. 업데이트를 `max_steps`번 한 뒤에 확인한 loss까지 포함해서, 끝내 `loss < tol`이 안 되면 `-1`
3. `tol`의 기본값은 `0.01`, `max_steps`의 기본값은 `1000`

| w, lr | 기타 | 출력 | 설명 |
| --- | --- | --- | --- |
| `0, 0.1` | — | `16` | |
| `0, 0.5` | — | `1` | 한 번에 w = 3 |
| `3, 0.1` | — | `0` | 처음부터 정답 |
| `10, 0.05` | — | `41` | |
| `0, 1.0` | — | `-1` | w가 0 ↔ 6 진동 |
| `0, 1.1` | — | `-1` | 발산 (학습률이 너무 큼) |
| `0, 0.1` | `max_steps=16` | `16` | 16번째 업데이트 직후 통과 |
| `0, 0.1` | `max_steps=15` | `-1` | 한 번 모자람 |

마지막 두 줄이 이 문제의 핵심입니다. "max_steps번 업데이트한 뒤의 loss"도 검사해야 합니다.
