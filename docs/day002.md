# Day 2 · 연산자, 형 변환, input, f-string

## 왜 배우는가

파일·사용자 입력·API 응답에서 들어오는 데이터는 대부분 **문자열**입니다(`"0.925"`). 계산하려면 숫자로 **변환**해야 하고, 학습 로그(`Epoch 03/10 | loss 0.1235 | acc 92.5%`)처럼 결과를 보기 좋게 **출력**하려면 f-string 포맷이 필요합니다.

---

## 1. 연산자 정리

```python
# 산술: + - * / // % **
print(2 ** 3 ** 2)   # 512  ← ** 는 오른쪽부터: 2 ** (3 ** 2)
print(-2 ** 2)       # -4   ← ** 가 부호(-)보다 먼저: -(2 ** 2)
print(7 / 2 * 2)     # 7.0  ← 같은 우선순위는 왼쪽부터

# 복합 대입
x = 7
x += 3    # x = x + 3
x *= 2    # x = x * 2
print(x)  # 20

# 비교: == != < <= > >=  → 결과는 bool (True / False)
print(3 > 2, 3 == 3.0, 1 < 2 < 3)   # True True True  ← 연쇄 비교 가능
print(type(3 > 2))                  # <class 'bool'>
print(True + True)                  # 2  ← bool 은 int 의 일종 (True=1, False=0)
```

우선순위(높은 → 낮은): `**` → 부호 `-x` → `* / // %` → `+ -` → 비교 → `not` → `and` → `or`.
헷갈리면 **괄호를 쓰는 게 정답**입니다.

## 2. 형 변환 (type conversion)

```python
print(int("3") + int("4"))   # 7
print("3" + "4")             # 34   ← 문자열끼리는 이어붙이기!
print(float("3.5"))          # 3.5
print(int(float("3.9")))     # 3    ← 소수 문자열 → int 는 float 를 거쳐야 함 (버림)
print(str(3.14))             # 3.14
print(bool(0), bool(""), bool("0"))   # False False True  ← "0" 은 비어있지 않은 문자열이라 True

int("3.5")   # ValueError: invalid literal for int() with base 10: '3.5'
```

`int()`, `float()`, `str()`은 "변환 함수"라기보다 **그 타입의 새 객체를 만드는 생성자**입니다. 원래 객체는 바뀌지 않습니다.

## 3. 부동소수점 오차

```python
print(0.1 + 0.2)                    # 0.30000000000000004
print(0.1 + 0.2 == 0.3)             # False  ← float 를 == 로 비교하면 위험!
print(abs((0.1 + 0.2) - 0.3) < 1e-9)  # True   ← 차이가 아주 작은지로 비교
print(round(2.5), round(3.5))       # 2 4    ← 반올림이 아니라 "짝수 쪽으로" (은행원 반올림)
print(round(2.675, 2))              # 2.67   ← 2.675 가 실제로는 2.67499999... 로 저장됨
```

`1e-9`는 `1 × 10⁻⁹ = 0.000000001`(과학적 표기법)입니다. 딥러닝 코드에서 `eps=1e-8`처럼 자주 봅니다.

## 4. input — 사용자 입력 받기

```python
age_text = input("나이를 입력하세요: ")   # 사용자가 25 입력
print(type(age_text))                     # <class 'str'>  ← 항상 문자열!
age = int(age_text)
print(age + 1)                            # 26
```

`input()`은 **무조건 str을 반환**합니다. 숫자 계산을 하려면 반드시 변환하세요.
(테스트에서는 키보드 입력을 흉내 내기 어려우므로, 오늘 문제는 "input으로 받은 것 같은 문자열"을 인자로 받습니다.)

## 5. f-string — 포맷 문자열

문자열 앞에 `f`를 붙이고 `{}` 안에 **아무 파이썬 식**이나 넣습니다. 어제 문제 5가 이렇게 짧아집니다.

```python
n, b = 1000, 32
print(f"샘플 {n}개 / 배치 크기 {b} → 배치 {(n + b - 1) // b}개")
```

`{값:포맷}` 형식으로 모양을 정합니다.

```python
acc = 0.87512
print(f"{acc:.2f}")        # 0.88        ← 소수점 둘째 자리 (반올림)
print(f"{acc:.1%}")        # 87.5%       ← ×100 하고 % 붙이기
print(f"{7:03d}")          # 007         ← 폭 3, 빈자리는 0 (d = 정수)
print(f"{12345678:,}")     # 12,345,678  ← 천 단위 쉼표
print(f"|{'ai':>5}|{'ai':<5}|")   # |   ai|ai   |  ← 오른쪽/왼쪽 정렬, 폭 5
print(f"{1 + 2 = }")       # 1 + 2 = 3   ← 디버깅용: 식과 값을 함께 출력
print(f"{3:0{4}d}")        # 0003        ← 폭 자리에 {} 를 또 넣을 수 있음 (중첩)
```

| 포맷 | 의미 | 예 |
| --- | --- | --- |
| `.Nf` | 소수점 N자리 | `f"{3.14159:.2f}"` → `3.14` |
| `.N%` | 퍼센트, 소수점 N자리 | `f"{0.5:.0%}"` → `50%` |
| `0Wd` | 정수, 폭 W, 0으로 채움 | `f"{5:03d}"` → `005` |
| `>W` `<W` `^W` | 오른쪽/왼쪽/가운데 정렬 | `f"{'a':^3}"` → ` a ` |
| `,` | 천 단위 쉼표 | `f"{1000:,}"` → `1,000` |

---

## 자주 하는 실수

1. **input 결과를 그대로 계산**: `input()` + 1 → `TypeError`. `"3" * 2`는 에러 없이 `"33"`이 되어 더 찾기 어렵습니다.
2. **`int("3.5")`**: 소수점이 있는 문자열은 바로 int가 안 됩니다 → `int(float("3.5"))`.
3. **float를 `==`로 비교**: `0.1 + 0.2 == 0.3`은 False. 차이의 절댓값 `abs(a - b)`가 아주 작은지로 비교하세요.
4. **f-string의 `f` 빼먹기**: `"{acc:.2f}"`는 그냥 글자 그대로 출력됩니다. 에러가 안 나서 놓치기 쉽습니다.

---

## 내부 동작 원리: 왜 0.1 + 0.2 ≠ 0.3 인가

float는 **IEEE 754 배정밀도(64비트)** 형식으로 저장됩니다: 부호 1비트 + 지수 11비트 + 가수(유효숫자) 52비트, 즉 `±1.xxxx(2진수) × 2^지수` 꼴입니다. 10진수에서 1/3이 0.333…으로 끝나지 않듯, 2진수에서는 **1/10이 0.0001100110011…으로 무한히 반복**됩니다. 52비트에서 잘라 가장 가까운 값으로 반올림하므로 `0.1`은 실제로 `0.1000000000000000055511…`로 저장되고, 이런 오차가 더해지면서 `0.1 + 0.2`는 `0.3`에 가장 가까운 float와 다른 값(`0.30000000000000004`)이 됩니다. `round(2.675, 2)`가 2.67이 되는 것도 2.675가 실제로 2.67499…로 저장되기 때문입니다. 반면 `0.5`, `0.25`처럼 2의 거듭제곱으로 표현되는 수는 정확히 저장됩니다. 딥러닝에서는 이 오차가 실제 문제가 됩니다: 아주 작은 수를 계속 곱하면 0이 되어버리는 **언더플로**, `log(0)` 같은 계산을 막으려고 `1e-8` 같은 작은 값(epsilon)을 더하는 관행, 그리고 메모리를 아끼려고 16비트 float(fp16, bf16)로 학습할 때 정밀도를 어떻게 지킬지가 모두 이 원리에서 나옵니다. 한편 f-string은 실행 시점에 `{}` 안의 식을 계산한 뒤 `format(값, "포맷")`을 호출해 문자열로 바꾸는 문법이고, 포맷 해석은 값의 타입이 맡습니다(그래서 문자열에 `:.2f`를 쓰면 `ValueError`).
