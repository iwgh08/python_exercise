# Day 4 · 반복문

## 왜 배우는가

딥러닝 학습 코드의 뼈대는 `for epoch in range(num_epochs):` 한 줄입니다. "손실이 충분히 작아질 때까지 계속" 같은 조건 반복은 `while`, early stopping의 "멈춘다"는 `break`입니다. 반복문을 정확히 쓰면 학습 루프를 직접 짤 수 있습니다.

---

## 1. for 와 range

```python
for i in range(3):          # 0, 1, 2  ← 3은 포함하지 않는다
    print(i, end=" ")
print()                     # 0 1 2

for i in range(1, 6):       # 1 ~ 5    ← range(start, stop): stop 은 미포함
    print(i, end=" ")
print()                     # 1 2 3 4 5

for i in range(10, 0, -3):  # 10, 7, 4, 1  ← range(start, stop, step)
    print(i, end=" ")
print()                     # 10 7 4 1

print(list(range(5, 5)))    # []  ← start >= stop 이면 한 번도 안 돈다
```

`range(a, b)`는 **a 이상 b 미만**입니다. 길이는 `b - a`. "1부터 N까지"는 `range(1, N + 1)`입니다.

`for`는 range만이 아니라 **하나씩 꺼낼 수 있는 것**(iterable)이면 무엇이든 돕니다. 문자열은 글자 하나씩 꺼내집니다.

```python
for ch in "AI!":
    print(ch, end="|")
print()                     # A|I|!|
```

## 2. 누적 패턴: 반복 전에 초기화, 반복 안에서 갱신

```python
total = 0                   # ① 반복 전에 시작값
for x in range(1, 5):
    total += x              # ② 매번 갱신 (total = total + x)
print(total)                # 10   ③ 반복이 끝난 뒤 사용

count = 0
for ch in "banana":
    if ch == "a":
        count += 1
print(count)                # 3
```

AI 코드에서 "epoch 동안 손실 합계 → 평균"이 정확히 이 패턴입니다.

## 3. while: 조건이 참인 동안 반복

```python
loss = 1.0
epoch = 0
while loss >= 0.1:          # 매 반복 "시작 전에" 조건을 다시 검사
    loss *= 0.5
    epoch += 1
print(epoch, loss)          # 4 0.0625
```

반복 횟수를 **미리 모를 때** `while`을 씁니다. 반복 안에서 조건에 쓰인 값(`loss`)이 바뀌지 않으면 영원히 끝나지 않습니다(무한 루프, `Ctrl+C`로 중단).

## 4. break 와 continue

```python
for ch in "ab3cd#ef":
    if ch == "#":
        break               # 반복문 전체를 즉시 탈출
    if ch == "3":
        continue            # 이번 회차만 건너뛰고 다음 회차로
    print(ch, end="")
print()                     # abcd
```

- `break`: 가장 가까운 반복문을 **끝낸다**.
- `continue`: 아래 코드를 건너뛰고 **다음 회차로** 간다.

## 5. for-else / while-else

`else` 블록은 **break 없이 반복이 끝까지 돌았을 때만** 실행됩니다. "찾다가 못 찾음"을 표현할 때 씁니다.

```python
n = 7
for d in range(2, n):
    if n % d == 0:
        print(n, "는 약수", d, "가 있음")
        break
else:                       # break 가 한 번도 안 일어났을 때
    print(n, "는 소수")      # 7 는 소수
```

if의 else와 헷갈리기 쉬워서 "no-break"라고 읽으면 기억하기 쉽습니다. 함수 안이라면 `return`으로 같은 일을 할 수도 있습니다.

```python
def has_zero(text):
    for ch in text:
        if ch == "0":
            return True     # 찾자마자 함수 종료 (break + 결과 반환)
    return False            # 반복을 다 돌았는데 못 찾음

print(has_zero("1205"), has_zero("123"))   # True False
```

## 6. 맛보기: 문자 비교

문자열도 `<`, `<=`로 비교할 수 있고, 연쇄 비교도 됩니다. 숫자 글자인지 확인할 때 유용합니다.

```python
ch = "7"
print("0" <= ch <= "9")     # True
print("0" <= "a" <= "9")    # False
print(ch.isdigit())         # True  ← 같은 일을 하는 문자열 메서드 (Day 5 이후 자세히)
```

---

## 자주 하는 실수

1. **range 끝 off-by-one**: `range(1, n)`은 n을 포함하지 않습니다. 1~n이 필요하면 `range(1, n + 1)`.
2. **누적 변수를 반복 안에서 초기화**: `for` 안에 `total = 0`을 두면 매번 0으로 돌아가서 마지막 값만 남습니다.
3. **while 조건 값을 갱신하지 않음**: `while loss >= 0.01:` 안에서 `loss`를 바꾸지 않으면 무한 루프입니다. 안전장치로 `max_steps` 같은 상한을 함께 두는 습관을 들이세요.

## 내부 동작 원리: for 는 "다음 거 줘"를 반복하는 while 이다

`for x in obj:`는 내부적으로 ① `it = iter(obj)`로 **이터레이터**를 얻고, ② `x = next(it)`를 반복 호출하다가, ③ 더 꺼낼 게 없을 때 이터레이터가 던지는 `StopIteration` 예외를 받아 조용히 반복을 끝냅니다. 즉 for문은 아래 while문을 짧게 쓴 것과 같습니다. `range`는 숫자를 미리 만들어 두는 목록이 아니라 `start`, `stop`, `step` 세 값만 기억하고 `next`가 불릴 때마다 다음 숫자를 계산하는 객체라서, `range(10**12)`도 메모리를 거의 쓰지 않습니다. 나중에 PyTorch의 `DataLoader`도 똑같이 이터레이터라서 `for batch in loader:`로 돌 수 있고, 그때그때 배치를 만들어 냅니다. for-else의 `else`는 ③의 "정상 종료" 경로에만 붙어 있는 코드라서, `break`로 빠져나가면 그 경로를 건너뛰어 실행되지 않습니다.

```python
it = iter("AI")
print(next(it), next(it))   # A I
# next(it)                  # StopIteration  ← for 는 이 예외를 보고 멈춘다

r = range(0, 10**12, 2)
print(r[3], len(r))         # 6 500000000000  ← 숫자를 만들지 않고 계산만 한다
```
