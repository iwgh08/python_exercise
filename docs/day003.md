# Day 3 · 조건문

## 왜 배우는가

모델은 "확률 0.83"을 내놓을 뿐이고, 그걸 **"positive"로 판정할지**, 검증 손실이 나빠졌을 때 **학습을 멈출지**(early stopping)는 조건문이 결정합니다. AI 코드의 "판단" 부분은 거의 다 `if`입니다.

---

## 1. if / elif / else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:     # 위 조건이 False 일 때만 검사
    grade = "B"
else:
    grade = "C"

print(grade)   # B
```

- 위에서부터 차례로 검사하고, **처음 True가 된 블록 하나만** 실행한 뒤 나머지는 건너뜁니다.
- 그래서 `elif score >= 80`에 도달했다면 이미 `score < 90`이 보장됩니다. `elif 80 <= score < 90`이라고 쓸 필요가 없어요.
- 블록은 **들여쓰기(공백 4칸)**로 구분합니다. 콜론 `:`을 빼먹으면 `SyntaxError`.

함수 안에서는 `return`이 함수를 즉시 끝내므로 `elif`/`else` 없이 쓸 수도 있습니다 (**early return**).

```python
def grade_of(score):
    if score >= 90:
        return "A"
    if score >= 80:        # 여기 왔다면 score < 90
        return "B"
    return "C"

print(grade_of(95), grade_of(85), grade_of(10))   # A B C
```

## 2. 조건 결합: and / or / not, 연쇄 비교

```python
prob = 0.97
print(prob >= 0.9 or prob <= 0.1)   # True   ← 둘 중 하나만 True 여도 True
print(0.4 < prob and prob < 0.6)    # False  ← 둘 다 True 여야 True
print(0.4 < prob < 0.6)             # False  ← 위와 같은 뜻 (연쇄 비교, 더 파이썬답다)
print(not prob > 0.5)               # False  ← not 은 비교보다 나중에 계산: not (prob > 0.5)
```

우선순위: `not` → `and` → `or`. `a or b and c`는 `a or (b and c)`입니다. 섞어 쓸 땐 **괄호**를 치세요.

조건식 자체가 bool이므로, bool을 돌려주는 함수는 if 없이 끝낼 수 있습니다.

```python
def is_passed(score):
    return score >= 60      # if score >= 60: return True else: return False 와 같다

print(is_passed(70), is_passed(30))   # True False
```

## 3. truthy / falsy

`if` 뒤에는 bool이 아닌 값도 올 수 있습니다. 파이썬은 `bool(값)`으로 바꿔서 판단합니다.

```python
# falsy (False 로 취급): 0, 0.0, "", None, 그리고 빈 컬렉션 [] {} ()
# truthy: 그 외 전부 — "0", " ", -1, "False" 도 truthy!
name = ""
if name:
    print("이름 있음")
else:
    print("이름 없음")      # 이름 없음

print(bool("False"), bool(" "), bool(0.0))   # True True False
```

**`None` 확인은 `is None`으로** 합니다. "값이 아직 없다"는 뜻의 `None`과 "값이 0이다"는 다른 상황이기 때문입니다.

```python
best_loss = 0.0              # 손실이 0인 것은 "기록 있음"
print(not best_loss)         # True   ← 0.0 도 falsy 라서 "기록 없음"처럼 보인다 (버그!)
print(best_loss is None)     # False  ← 정확한 판단
```

## 4. 단락 평가 (short-circuit)

`and`/`or`는 **결과가 이미 정해지면 오른쪽을 계산하지 않습니다.**

- `A and B`: A가 falsy면 B를 보지 않고 A를 반환
- `A or B`: A가 truthy면 B를 보지 않고 A를 반환

```python
best = None
val = 0.5

# print(val < best)                    # TypeError: '<' not supported between 'float' and 'NoneType'
print(best is None or val < best)      # True   ← 왼쪽이 True 라 오른쪽은 실행조차 안 됨
# print(val < best or best is None)    # TypeError ← 순서를 바꾸면 터진다!

total = 0
print(total != 0 and 10 / total > 0.5) # False  ← ZeroDivisionError 가 나지 않는다
```

그리고 `and`/`or`는 **True/False가 아니라 피연산자 자체를 반환**합니다.

```python
print("" or "unknown")      # unknown   ← 빈 문자열이면 기본값 쓰기 관용구
print("gpt" or "unknown")   # gpt
print(0 and 5)              # 0
print(3 and 5)              # 5
```

## 5. 맛보기: 조건 표현식 (한 줄 if)

```python
prob = 0.7
label = "positive" if prob >= 0.5 else "negative"
print(label)   # positive
```

`값1 if 조건 else 값2`. 간단한 둘 중 하나 선택에만 쓰고, 복잡하면 일반 if문이 낫습니다.

## 자주 하는 실수

1. **elif 순서 오류**: `if score >= 60: "D"`를 먼저 쓰면 95점도 D가 됩니다. 범위가 겹치면 **좁은(엄격한) 조건부터** 검사하세요.
2. **`if x == 1 or 2:`**: `(x == 1) or 2`로 해석돼 항상 truthy입니다. `x == 1 or x == 2`로 쓰세요.
3. **`None`을 `not x`로 검사**: 0, 0.0, ""도 걸려듭니다. `x is None`을 쓰세요.

## 내부 동작 원리: if는 "점프"이고, and/or는 "갈림길"이다

파이썬 코드는 실행 전에 **바이트코드**라는 명령어 목록으로 컴파일되고, `if`는 그 안에서 "조건이 거짓이면 몇 번 명령으로 건너뛰어라(`POP_JUMP_IF_FALSE`)"라는 점프 명령이 됩니다. 이때 조건값을 참/거짓으로 판정하는 규칙이 truthiness입니다. 객체에 `__bool__` 메서드가 있으면 그 결과를, 없으면 `__len__`이 0인지를 보고, 둘 다 없으면 True로 칩니다. 그래서 빈 리스트는 길이 0이라 falsy, 직접 만든 클래스의 객체는 기본적으로 truthy입니다(나중에 PyTorch의 `if tensor:`가 원소가 여러 개일 때 에러를 내는 것도 텐서의 `__bool__`이 "참/거짓이 애매하다"며 예외를 던지기 때문입니다). `and`/`or`도 점프로 구현됩니다. `A or B`는 "A를 계산해 스택에 둔다 → A가 truthy면 B 계산 부분을 건너뛰고 A를 결과로 쓴다 → 아니면 A를 버리고 B를 계산한다"는 순서라서, 오른쪽이 아예 실행되지 않는 단락 평가와 "피연산자 자체를 반환"하는 성질이 동시에 나옵니다. 아래 코드로 직접 확인할 수 있습니다.

```python
import dis
dis.dis("a or b")   # COPY / POP_JUMP_IF_TRUE (버전에 따라 JUMP_IF_TRUE_OR_POP) 가 보인다
```
