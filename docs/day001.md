## 1. print — 화면에 출력하기

```python
print("Hello, AI")
print("loss:", 0.25)               # 여러 값은 쉼표로 → 사이에 공백 자동 삽입
print("a", "b", sep="-", end="!\n")
```
```
Hello, AI
loss: 0.25
a-b!
```

- `sep`: 값 사이 구분자 (기본 `" "`), `end`: 마지막에 붙는 문자 (기본 `"\n"` 줄바꿈)

## 2. 변수 — 값에 붙이는 이름표

```python
learning_rate = 0.001
epochs = 10
model_name = "my_cnn"
print(type(learning_rate), type(epochs), type(model_name))
```
```
<class 'float'> <class 'int'> <class 'str'>
```

핵심: **파이썬 변수는 "상자"가 아니라 "이름표"** 입니다.
`x = 10`은 "10이라는 객체를 만들고, 그 객체에 `x`라는 이름표를 붙인다"는 뜻입니다.

```python
x = 10
print(id(x))   # 객체의 고유 번호(메모리 주소 비슷한 것)
x = x + 1
print(id(x))   # 번호가 바뀜! 10이 11로 바뀐 게 아니라, 11이라는 새 객체로 이름표를 옮긴 것
```
```
140712035896024
140712035896056
```
(숫자는 실행할 때마다 다르지만, 두 값이 **다르다**는 점이 중요합니다.)

## 3. 숫자: int, float

```python
print(7 / 2)    # 3.5   ← 나눗셈은 항상 float
print(6 / 3)    # 2.0   ← 나누어떨어져도 float!
print(7 // 2)   # 3     ← 몫 (floor division)
print(7 % 2)    # 1     ← 나머지
print(2 ** 10)  # 1024  ← 거듭제곱
print(int(3.9)) # 3     ← 반올림이 아니라 소수점 버림
print(0.1 + 0.2)  # 0.30000000000000004 (Day 2에서 자세히)
```

### `//`와 `%`는 짝꿍

항상 다음 식이 성립합니다: **`a == (a // b) * b + (a % b)`**

```python
n_samples = 1000
batch_size = 32
print(n_samples // batch_size)  # 31 → 꽉 찬 배치 31개
print(n_samples % batch_size)   # 8  → 남는 샘플 8개
```

시간 변환도 같은 원리입니다: `125초 → 125 // 60 = 2분, 125 % 60 = 5초`.

## 4. 문자열: str

```python
s = "hello"
print(s[0], s[-1])        # h o   ← 인덱스 0부터, -1은 맨 뒤
print(s.upper())          # HELLO
print("AI" + "model")     # AImodel   ← + 는 이어붙이기
print("ha" * 3)           # hahaha
print(len("파이썬"))       # 3
print(str(42) + "!")      # 42!   ← 숫자를 문자열로 바꿔야 이어붙일 수 있음
```

맛보기(Day 2에서 본격적으로): f-string을 쓰면 더 편합니다.

## 5. 오늘 문제를 위한 함수 틀 읽는 법

함수는 Day 8에서 제대로 배우지만, 오늘 문제는 아래처럼 **틀이 주어지고 몸통만 채우는** 형태입니다.

```python
def double(x):
    """x의 두 배를 반환한다."""
    return x * 2      # ← return 뒤에 '결과값'을 쓰면 됩니다

print(double(5))      # 10
```

`print`는 화면에 보여주기만 하고, `return`은 결과를 **돌려줍니다**. 테스트는 `return` 값을 검사하므로 반드시 `return`을 쓰세요.

## 자주 하는 실수

1. **문자열 + 숫자**
   ```python
   "나이: " + 25        # TypeError: can only concatenate str (not "int") to str
   "나이: " + str(25)   # OK
   ```
2. **`/`의 결과를 정수로 착각**: `10 / 2`는 `5`가 아니라 `5.0`. 개수를 셀 때는 `//`를 쓰세요.
3. **음수의 `//`, `%`**: `-7 // 2`는 `-3`이 아니라 **`-4`**, `-7 % 2`는 `1`.
   `//`는 "0 쪽으로 자르기"가 아니라 "**더 작은 쪽(바닥)으로 내림**"이기 때문입니다. 그래야 `a == (a//b)*b + a%b`가 유지됩니다: `(-4)*2 + 1 = -7` ✔

## 내부 동작 원리: 파이썬에서는 모든 것이 객체다

`x = 10`을 실행하면 파이썬은 (1) 메모리에 정수 객체 `10`을 만들고 — 이 객체는 값(10)뿐 아니라 **타입 정보(int)와 참조 횟수**를 함께 가지고 있습니다 — (2) 현재 이름 공간(namespace, 사실상 `{"x": <객체 주소>}` 형태의 딕셔너리)에 `x`라는 이름을 등록해 그 객체를 가리키게 합니다. 그래서 `type(x)`는 변수가 아니라 **객체에게** 타입을 물어보는 것이고, 같은 이름 `x`에 나중에 문자열을 넣어도 에러가 나지 않습니다(동적 타이핑). 또한 `int`, `float`, `str`은 **불변(immutable)** 객체라서 `x = x + 1`은 기존 객체를 고치지 못하고 새 객체 `11`을 만들어 이름표만 옮깁니다 — 위에서 `id`가 바뀐 이유입니다. 아무 이름도 가리키지 않게 된 객체는 참조 횟수가 0이 되어 자동으로 메모리에서 해제됩니다. 참고로 파이썬 int는 크기 제한이 없어서 `2 ** 1000`도 정확히 계산되지만, float는 64비트 이진수로 저장되므로 `0.1`처럼 이진수로 딱 떨어지지 않는 값은 근삿값이 됩니다. 이 "이름표" 모델은 Day 5(리스트는 참조), Day 13(가변·불변, 복사)에서 버그를 이해하는 열쇠가 됩니다.
